# Atelier v2 — 楽器を、創る。

既存の楽器を種に、**物理モデルの音色空間**を動かして自分だけの楽器を創り、演奏し、
**DAW へ持ち出せる**（WAV / SFZ マルチサンプル / MIDI）ブラウザアプリです。バックエンドなし、データは端末内のみ。

**▶ ブラウザでそのまま試す: https://taitimusic.github.io/atelier/**（Chrome / Edge 推奨）

## 中心の考え方

> 楽器 ＝ 一貫した音色の**領域** ＋ 演奏との**対応づけ** ＋ **同一音源性**

v1 はこの定義を掲げながら、音源が「加算 6 倍音＋フォルマント」の汎用シンセだったため、
どの楽器も同じ薄い音が衣装を替えているだけに聞こえ、定義を音で証明できませんでした。
v2 はこの定義を**音源の構造そのもの**で満たします。

| 定義 | v2 での実体 |
|---|---|
| 同一音源性 | すべての音が同じ**モード共鳴体**（弦・棒・鐘・膜…の固有振動）と同じ**胴**を共有する。打っても擦っても吹いても「同じ物体」が鳴る |
| 領域 | 全パラメータが**連続量**（励起は「種類」ではなく打撃・擦る・息の**混合比**）。どの中間点も物理的にありうる物体として鳴るので、モーフが途切れない |
| 対応づけ | **変調マトリクス**: ベロシティ・音高・押し込み・MPE スライド・マクロ… → 任意のパラメータ。これが演奏で辿る領域の形を決める |

そして「楽器は点ではなく面である」を**目に見える形**にしました（領域マップ）。

## 起動

```bash
pnpm install
pnpm dev          # http://localhost:5190
pnpm build        # 型検査＋本番ビルド（dist/）
pnpm preview      # ビルドの確認
pnpm test         # 単体テスト（Vitest）
pnpm bench        # 合成コアの CPU 予算ベンチ（16 声・最悪ケース）
pnpm render       # 種楽器のオフライン試聴 WAV（Node・合成コアのみ）→ out/renders/node/
```

ブラウザでの自動検査（Playwright の Chromium / Firefox が必要: `npx playwright install chromium firefox`）:

```bash
pnpm build && pnpm preview --port 5191   # 別のターミナルで
pnpm smoke            # Chromium: 発音・全種・ループ・アルペジオ・ライブラリ・書き出し・共有リンク・モバイル幅 → out/screens/
pnpm smoke:xb         # Firefox / WebKit の最小確認
pnpm render:browser   # 実際の書き出し経路で全種＋交配のデモ WAV → out/renders/browser/
```

出力先は環境変数 `ATELIER_OUT` で変えられます。

`main` へ push すると GitHub Actions（`.github/workflows/pages.yml`）が検査・ビルドして GitHub Pages へ公開します（`/atelier/` 配下なので `--base=/atelier/` でビルド）。

Chrome / Edge 推奨（Web MIDI）。Firefox でも演奏とデモ WAV 書き出しを確認済み。Safari は未検証です。

## できること

**創る**
- **29 の種楽器**: ピアノ、エレピ、チェンバロ、ナイロン／スチール弦ギター、ハープ、箏、バイオリン、チェロ、グラスハーモニカ、フルート、クラリネット、尺八、マリンバ、ビブラフォン、グロッケン、カリンバ、オルゴール、スチールパン、調律鐘、シンギングボウル、ティンパニ、ハンドドラム、スネア、808、ハイハット、合唱、パッド、サブベース
- **ブレンド・パッド**: 4 隅に楽器（種・マイ楽器・「いまの音」）を置き、点を動かして連続的に混ぜる。動かしている間は自動で試奏
- **領域マップ**: 横＝明るさ、縦＝持続と柔らかさ。現在の楽器が音域×強弱で覆う**領域を網目で描画**し、弾いている音がその中のどこにいるかを光点で表示。**同一音源性スコア**（領域の段差を検出）
- **発見**: 今の音の近傍に 8 つの変奏。変化の大きさ・対象グループを選び、採用すると次の世代へ。ロックしたつまみは動かない
- **造形（全パラメータ）**: 励起（打撃・硬さ・打点／擦る・吹く・息・ざらつき・ADSR／ノイズ層）、共鳴体（構造・剛性・明るさ・偶数モード・響き・高域減衰・ダンパー・揺らぎ）＋**モード構造の可視化**、ピッチ（落下・ビブラート・ゆらぎ）、胴（3 共鳴）＋**周波数特性表示**、EQ・コーラス・ディレイ・リバーブ
- **変調マトリクス**: 8 つの演奏ソース＋LFO＋Mod エンベロープ＋8 マクロ。変調源を選んでつまみをドラッグするだけで割当（つまみの周囲に量の弧）
- **マクロ 8 本**: 名前を付けられる演奏用コントロール。MIDI Learn 対応
- **ジェスチャ単位の Undo/Redo**、**A/B 比較**、右クリックで値の直接入力・ロック・変調追加

**弾く**
- 鍵盤（手前ほど強く・押したまま上下でアフタータッチ・グリッサンド）、**等間隔グリッド**（押したまま横＝その音だけベンド、縦＝スライド。MPE 的）、**弦**（なぞる速さ＝強さ。和音モード／音階モード: 平調子・雲井・琉球…）、パッド
- PC キーボード（A〜; ＝ C〜E、Z/X オクターブ、C/V ベロシティ、Space サステイン、Esc 全消音）
- **Web MIDI / MPE**: ベロシティ、チャンネル／ポリ・アフタータッチ、ベンド（MPE 時 ±48）、CC74、CC1、CC64
- アルペジエータ（上行・下行・上下・押した順・ランダム、4 分〜32 分、1〜3 オクターブ、ラッチ）
- **ループ録音**: 弾いてループにし、**鳴らしたまま音色を彫り続ける**。重ね録り、MIDI 書き出し、WAV 書き出し
- **調律**: 12 平均律、純正律、ピタゴラス、1/4 コンマ・ミーントーン、倍音列、19/22/24/31/53 平均律、スレンドロ・タイ近似、ボーレン＝ピアース、**Scala (.scl) 読み込み**。音律を楽器に保存可能

**持ち出す**
- **マルチサンプル書き出し（WAV＋SFZ の ZIP）**: 音域・間隔・強弱の段数・長さを指定。SFZ 対応サンプラーで DAW から使える
- 音声録音（出力をそのまま 24bit WAV）、デモ WAV、ループの WAV / MIDI
- `.atelier`（JSON）書き出し・読み込み、**共有リンク**（楽器を URL に圧縮埋め込み・サーバ不要）
- `.atelier` / `.mid` のドラッグ＆ドロップ読み込み

## 構成

```
src/
  engine/            音（DOM 非依存。AudioWorklet とオフライン描画で共有）
    params.ts        全パラメータの単一正本（範囲・尺度・既定・説明）＋変調源
    modes.ts         モード比ファミリ（modeTable.ts は modesCompute.ts の物理式から生成）
    synth.ts         合成コア: ボイス管理・変調マトリクス・モード共鳴体・持続駆動・ノイズ層
    processor.ts     AudioWorklet（合成＋録音）
    fx.ts            胴・EQ・コーラス・ディレイ・生成 IR リバーブ（ネイティブノード）
    engine.ts        AudioEngine（UI との唯一の境界）＋ オフライン描画
    instrument.ts    楽器データ（.atelier）・検証・ブレンド
    descriptors.ts   解析的な音色記述子・領域・同一音源性・モード可視化
    tuning.ts        音律・Scala
  presets/seeds.ts   種楽器 29 種
  io/                WAV・ZIP・SFZ マルチサンプル・MIDI ファイル・共有リンク
  input/             Performer（全入力の合流点・アルペジオ・ループ）・MIDI/MPE・PC キーボード
  state/             Zustand ストア（履歴・A/B・ブレンド・発見）・IndexedDB ライブラリ
  ui/                画面
tests/               単体テスト
scripts/             ベンチ・Node 試聴描画・ブラウザ検査（smoke.mjs）・ブラウザ試聴描画
docs/DESIGN.md       設計の詳細（DSP モデル・データ形式・対応づけの意味論・計測値・限界）
```

## ファイル形式

`.atelier` は人間が読める JSON（物理値で保存）。詳細は [docs/DESIGN.md](docs/DESIGN.md)。
v1 の `.atelier`（`version: "1.x"`）とは互換性がありません（音源モデルが別物のため）。
